# KitabGhar E-Books Directory (কিতাবঘর ই-বুক ফোল্ডার)

Put all your e-book PDF / EPUB files in this folder on your cPanel server:
Location: public_html/ebooks/

Example:
If you put a file named "python-bangla.pdf" here:
File path on server: public_html/ebooks/python-bangla.pdf
Website link: /ebooks/python-bangla.pdf
Full URL: https://yourdomain.com/ebooks/python-bangla.pdf

In your Admin Panel or products.json:
Set "downloadUrl": "/ebooks/python-bangla.pdf"

Users will directly download the PDF from this link when clicking "ডাউনলোড করুন"!
