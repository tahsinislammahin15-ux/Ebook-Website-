**KitabGhar (কিতাবঘর)** is a high-performance, mobile-first digital bookstore designed specifically for selling paid e-books via **WhatsApp & Mobile Banking (bKash & Nagad in BDT)** and providing **instant direct downloads for free e-books**.

## 🚀 How to Build & Push to GitHub (গিটহাবে আপলোড করার নিয়ম)

Follow these simple steps in your local terminal or Git Bash to publish this project to your GitHub account:

### Step 1: Create a New Repository on GitHub
1. Open [github.com/new](https://github.com/new) in your browser.
2. Enter a repository name, for example: `kitabghar` or `ebook-store`.
3. Choose **Public** or **Private**.
4. **Do not** initialize with a README, .gitignore, or license (we already have them ready).
5. Click **Create repository**.

### Step 2: Initialize Git and Push Your Code
Open your terminal inside this project folder and run:

```bash
# 1. Initialize local git repository
git init

# 2. Add all files to git tracking
git add .

# 3. Create initial commit
git commit -m "Initial commit: KitabGhar E-Book Store with WhatsApp Checkout"

# 4. Set default branch to main
git branch -M main

# 5. Connect to your GitHub repository (replace with your GitHub username & repo name)
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git

# 6. Push code to GitHub
git push -u origin main
```

## ⚙️ Automated GitHub Actions Build

A pre-configured GitHub Actions workflow is included at `.github/workflows/deploy.yml`:

1. **Automatic Build**: Every time you `git push` to `main`, GitHub automatically installs dependencies (`npm install`) and compiles the static site (`npm run build`).
2. **Download Production Files**:
   - Go to your GitHub repository -> **Actions** tab.
   - Click on the latest workflow run.
   - Under **Artifacts**, download `kitabghar-cpanel-dist.zip`.
   - Extract the contents and upload them directly into your cPanel `public_html/` directory!
3. **Optional GitHub Pages**: If enabled in your repository's **Settings -> Pages** (Source: GitHub Actions), GitHub will host your storefront for free!

## 🌐 How to Deploy on cPanel Hosting

### Method 1: Upload Built Files to `public_html` (Recommended & Simplest)
1. In your local terminal, run:
   ```bash
   npm run build
   ```
   *(Or download the `kitabghar-cpanel-dist` artifact generated by GitHub Actions).*
2. Open your **cPanel File Manager**.
3. Navigate to `public_html/` (or your domain/subdomain root directory).
4. Upload all files and folders from inside the `dist/` directory:
   - `index.html`
   - `assets/` (JS & CSS bundles)
   - `products.json` (Catalog database)
   - Any images/covers
5. Done! Your website is live immediately at your domain.

### Method 2: Using cPanel Git™ Versioning
1. Log in to your **cPanel**.
2. Click **Git™ Versioning** under the **Files** section.
3. Click **Create** and paste your GitHub repository clone URL:
   `https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git`
4. Set Repository Path: `repositories/kitabghar`
5. After cloning, run `npm install && npm run build` via cPanel Terminal or SSH, and symlink/copy the `dist/` folder to `public_html/`.

### Method 3: Automated FTP Deployment via GitHub Actions
We've included an automated FTP deployment workflow template at:
`.github/workflows/cpanel-ftp-deploy.yml.example`

To enable automatic upload on every `git push`:
1. In GitHub Repository: Go to **Settings -> Secrets and variables -> Actions**.
2. Add secrets:
   - `CPANEL_FTP_SERVER` (e.g. `ftp.yourdomain.com` or server IP)
   - `CPANEL_FTP_USERNAME`
   - `CPANEL_FTP_PASSWORD`
3. Rename the file to `cpanel-ftp-deploy.yml` (remove `.example`).
